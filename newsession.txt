Key architecture notes

- Alpine x-ignore: any DOM clone appended to <body> must have clone.setAttribute('x-ignore', '') to prevent
  Alpine's MutationObserver from re-initializing x-model inputs and blanking their values.

- Drag-and-drop: shared touch drag state (_touchDragTarget: 'scope'|'materials', dragIndex, dropIndex,
  _dragClone, etc.). Scope uses touchDragStart/touchDragMove/touchDragEnd. Materials uses matTouchDragStart +
  the same move/end handlers. Mouse drag uses separate scopeDrag*/matDrag* method sets.
  Material <tr> clones are wrapped in a <table>/<tbody> before appending to body so they render correctly.

- Auto-save: in-progress estimate is auto-saved to localStorage key 'estimator-draft' via debounced input
  listener (800ms) + $watch on array lengths. Restored on init(). Cleared by _resetEstimate().
  Photos are excluded from draft if localStorage quota is exceeded.

- PDF header layout: logo goes top-LEFT (not right). y-cursor advances by logoH after drawing the logo,
  so the "Project Estimate" title never overlaps the logo even when no company info is filled in.

- Settings are stored in localStorage key 'estimator-settings'. Only settings are synced to Firebase;
  estimates are saved to Firebase separately via the cloud save/load UI.

- Cache-bust query strings: bump ?v=N on css/styles.css and js/app.js in index.html when releasing.
  Also bump versionCode/versionName in android/app/build.gradle.

- index.html is directly testable in a browser (no build step needed) for UI/logic changes.
